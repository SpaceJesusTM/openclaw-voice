# Reuse and licenses

This minimal integration adapts the deployment pattern, Google command wrapper,
and Calendar/Gmail skills from
https://github.com/SpaceJesusTM/tari-public (MIT license), audited against
commit c43455a43f59a554fd6e9e96934741ac4397a27d.
The complete copyright and permission notice is preserved in
[licenses/tari-public-MIT.txt](licenses/tari-public-MIT.txt).

It pins OpenClaw 2026.9.9 and gogcli 0.40.0 for compatibility with that
tested source. Those upstream components have independent licenses.

No production Tari credentials, personal memory, mutable state, Gmail content,
or Google tokens are included in this repository.
